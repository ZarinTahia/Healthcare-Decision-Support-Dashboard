#Patient Visiting Record Dashboard (Power BI)
##Project Overview

The Dashboard is an interactive Power BI report designed to analyze clinic's  performance metrics on a monthly basis.

It provides insights into patient volume, wait times, satisfaction scores, referrals, and demographic distributions to support operational decision-making.

This dashboard helps clinic's administrators and healthcare analysts:

- Monitor performance
- Identify peak hours and patient trends
- Evaluate service efficiency
- Improve patient satisfaction

## Dashboard Features
1. Key Performance Indicators (KPIs)

- Number of Patients
- Average Wait Time
- Patient Satisfaction Score
- Number of Patients Referred

These KPIs provide a quick overview of the clinic's performance for the selected month.

2. Patient Admission Analysis

- Admitted vs Not Admitted distribution
- Percentage breakdown of total patients

3. Service Efficiency

- % of Patients Seen Within 30 Minutes
- Target Met vs Target Missed visualization

4. Demographic Insights
- Patients by Age Group
- Patients by Gender
- Patients by Race

5. Operational Trends

- Patients by Day of the Week
- Patients by Hour (Heatmap View)
- Department Referrals Breakdown

## Tools & Technologies

- Microsoft Power BI
- Data Modeling (Relationships, Calendar Table)
- DAX (Data Analysis Expressions)
- Interactive Filters & Slicers
- KPI Cards, Donut Charts, Bar Charts, Heatmaps

## Time-Based Filtering

The dashboard includes a Month & Year slicer that allows users to dynamically analyze performance for different time periods.

## Business Objectives

This dashboard aims to:

- Improve clinic's operational efficiency
- Identify peak load hours
- Monitor wait-time performance
- Analyze referral patterns
- Support data-driven healthcare decisions

## Data Model

The dashboard uses:
- Transactional data
- Calendar table for time intelligence
- Cleaned and structured dataset for reporting
